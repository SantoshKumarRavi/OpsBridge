# Frontend patterns lab

An educational microfrontend that keeps the product surfaces separate while showing React Hooks, Redux Toolkit, reusable/memoized components, `useMemo`, `useCallback`, Material UI, Bootstrap, Tailwind, responsive layout, and labelled controls in one page. Next.js remains the SSR/SEO example; this lab is CSR.

Run it through the root npm workspace with `npm run dev:ui-patterns`. It is listed in the Compose `apps` profile at port 4301.
